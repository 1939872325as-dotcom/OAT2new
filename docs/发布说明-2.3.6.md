# 发布说明 · OTA2new v2.3.6

> 版本：`2.3.6`（`app/OAT/tools/settings.py` → `APP_VERSION`）
> 性质：**完整配置包 + 新目录结构 + 文档更新**（业务代码与 2.3.5 一致）

## 一、这个版本有什么

### 1. 全量配置打包

- 打包内含作者本机 `app/OAT/source/` 下的**全部模式与子模式**（魂土 / 魂王 / 业原火 / 觉醒 / 爬塔 / 灵染 / 御灵 / 契灵 / 绘卷，以及自定义模式），解压即用。
- 含各模式的 `config.json`、模板图、停止点击条件图（`stop/`）与 `mode.json`。
- 含 `app/OAT/tools/settings.json` 的本机习惯设置（窗口尺寸、抓屏模式、上次模式等）。

### 2. 新目录结构

```
OAT2new/
├── 启动OAT2.exe     便携启动器（自动切到 app\ 再启动）
├── 使用说明.txt
└── app/             程序目录
    ├── OAT2.exe
    ├── *.dll / *.pyd
    ├── OAT/         业务源码（热加载）
    ├── rapidocr/    OCR 模型
    ├── yyx/         多开启动器
    └── logs/        运行日志
```

- 根目录只有启动器与说明，运行库收进 `app/`，不再散落 60 多个文件。
- `启动OAT2.exe` 会先切到 `app\` 再运行 `OAT2.exe`，保证日志、热更新、更新器的工作目录正确。

### 3. 停止点击说明

- README 新增「停止点击（出现图片停止点击）」完整章节：配置步骤、运行时判定、日志、典型场景、注意事项。
- `docs/项目特点.md` 新增「重点功能四：停止点击」，并更新四个功能的配合链路。

### 4. README 重写

- 改为**功能导向**：功能一览 → 快速开始 → 拟人化点击 → 停止点击 → 识别与流程 → 配置与编辑器 → 日志排障 → 源码/打包 → 文档 → 许可证。
- 不再维护与历史版本的变更清单/差异表，只介绍当前实现的功能。

### 5. 版本号

- `app/OAT/tools/settings.py` → `2.3.6`（本次不升版本，资产按新结构重新上传）。

## 二、升级注意

1. **覆盖安装会覆盖配置**：本包含作者全量配置，若你已有自己的 `app/OAT/source/` 与 `app/OAT/tools/settings.json`，请先备份再合并。
2. **运行方式**：解压后双击 `启动OAT2.exe`（建议管理员）；也可直接运行 `app\OAT2.exe`。
3. **不要拆包**：`app/` 内文件必须与 `app\OAT2.exe` 保持同目录，单独移动会起不来。
4. **热更新**：改 `app/OAT/**.py` 后重启程序生效。
5. **GPU（可选）**：发布包为控制体积未附带 CUDA / cuDNN 运行库，默认走 CPU；需要 GPU 时按 [2.3.5 发布说明](./发布说明-2.3.5.md) 的说明自行放置 CUDA 13 / cuDNN 9 运行库。

## 三、验证

- `app/OAT/source/mode.json` 与全部模式目录存在；
- 打包清单不含 CUDA / cuDNN 运行库、日志、`__pycache__`、`.bak`。
